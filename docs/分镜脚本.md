# 90 秒项目演示 · 分镜脚本

> 配套字幕文件：`字幕.srt`（直接导入剪映）
> 封面：`封面.png`

## 一、录屏素材（先录这三段）

| 段 | 录什么 | 时长 | 注意 |
| --- | --- | --- | --- |
| **A** | 招聘网站 JD 页面，鼠标缓慢下滑 | 8 秒 | 选一条真实的 AI 岗 JD |
| **B** | 工具操作：粘贴简历 → 粘贴 JD → 点「开始分析」→ 出结果 | 25 秒 | 提前把两段文本复制好，别现场打字 |
| **C** | 结果页细节：分项评分 → 要求分级 → 缺失清单 → 简历质量 → 导出报告 | 20 秒 | 鼠标在重点数字上停 1–2 秒 |

录屏设置：1920×1080，30fps，鼠标别乱晃。

## 二、分镜表

| 时间 | 画面 | 字幕（见 SRT） | 剪辑要点 |
| --- | --- | --- | --- |
| 0–6s | 段 A，JD 页面滚动 | 投简历最烦的／是对着 JD 一条条比 | 开头别放自我介绍，直接上痛点 |
| 6–13s | 工具首页 + 标题卡 | 我做了个工具／10 秒告诉你够不够格 | 标题字大、居中 |
| 13–15s | 过渡 | — | 可加一个 0.5 秒转场 |
| 15–30s | 段 B：粘贴 → 分析 | 左边贴简历／右边贴 JD／点一下分析／结果立刻出来 | 等待过程 2x 加速 |
| 30–40s | 结果页：82% + A | 匹配度 82%／A 级 | **数字放大 150%，加红框** |
| 40–52s | 段 C：分项 + 要求分级 | 它拆成了分项／必须项 4 个全中／加分项漏了不影响 | 4/4 这个数字放大 |
| 52–68s | 段 C：缺失 + 简历质量 | 缺什么、先补哪个／简历哪句写得不好 | 鼠标划过高亮项 |
| 68–78s | 文字卡：为什么不用大模型 | 没用大模型／因为用户要的是"为什么 68 分" | 纯色背景 + 大字 |
| 78–86s | 文字卡：80% | 10 条真实 JD 留出集／吻合率 80% | 数字跳动动画（剪映「动画-数字」） |
| 86–90s | GitHub 仓库页 | 代码开源，链接在简介 | 结尾停 2 秒，别急切黑 |

## 三、剪映操作清单

```
① 新建项目 → 导入 A/B/C 三段录屏
② 按分镜排序，掐头去尾
③ 等待/加载片段 → 右键变速 2x
④ 文本 → 智能字幕 → 识别字幕 → 校对
⑤ 选字幕 → 右键文本朗读 → 选音色（或用自己录音）
⑥ 重点数字：复制到画中画 → 放大 150% → 贴纸加红框
⑦ 音频 → 音乐素材 → 搜"科技" → 音量 -20dB
⑧ 封面：选一帧 → 加标题「10 秒判断你够不够格」
⑨ 导出：1080P / 30fps / MP4
```

## 四、四个加分细节

1. **每 3–5 秒换画面**，静止超过 5 秒会显得卡
2. **数字一定要放大**：82%、4/4、80%
3. **字幕加描边**，深色浅色背景都能看清
4. **BGM 压到 -20dB**，不能盖过人声

## 五、常见翻车

| 问题 | 后果 |
| --- | --- |
| 开头 10 秒自我介绍 | 观众直接划走 |
| 画面静止不动 | 像 PPT 录屏，不专业 |
| 字幕错字没改 | 一眼看出赶工 |
| 没有结尾 CTA | 看完不知道去哪找代码 |
